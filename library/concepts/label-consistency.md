# ラベルの命名と粒度の一貫性

同じ一覧、同じ階層、同じファセットに並ぶラベルを、観点、粒度、構文、語の水準でそろえるための評価基準である。ia-taxonomyとia-structureで命名するとき、ia-evaluationでルーブリックR-03を点検するときに使う。

## 基準

1. ラベルを一貫させる。一貫性は予測しやすさを生み、少数のラベルから残りの見当を付けられるようにする [CLAIM-0034]。
2. 同じ体系の中では、動詞、名詞、疑問文などの構文の形式を1つにそろえる [CLAIM-0035]。
3. 同じ体系の中では、具体性（粒度）がおおむね等しいラベルを並べる [CLAIM-0036]。
4. 同じ種類の項目を並べるときは、目立つ欠けを作らない [CLAIM-0037]。
5. 語の水準（くだけた語か、正式または専門的な語か）を全体でそろえる [CLAIM-0012]。
6. 主な利用者の言葉を使う。利用者層ごとに用語が大きく異なる場合は、同じコンテンツでも層ごとに別のラベルの体系が必要になることがある [CLAIM-0038]。優先ラベルの選択でも、利用者が最も引きそうな語を優先する [CLAIM-0013]。

## 適用条件

- 基準3の例外として、索引のように粒度の異なる語を並べる仕組みがある [CLAIM-0036]。
- 基準6の別体系は、専門家と一般の利用者のように用語が大きく異なる層がある場合に限る [CLAIM-0038]。

## 代表ケースとの対応

ルーブリックR-03の「同じ役割の兄弟項目、または同じファセット内の項目が、同じ観点・粒度で付けられ、利用者の語で書かれている」に対応する。不適切な例「同じ親の下に『家事代行』と『北地区』が混在する」は、基準3の粒度ではなく観点（サービス種別と地区という別のファセット）の混在であり、ファセット分類の本文（KN-006）とあわせて点検する。

## 仮説・補完

次の内容は登録済みの文献主張に基づかない。

- 日本語のラベルでは、体言止め（「料金」）と文（「料金を確かめる」）の混在が基準2の構文の不一致に当たると考えられる。
- 社内略語や部署名だけのラベル（R-03の不合格例）は、基準6の「利用者の言葉」に反する例として扱える。
